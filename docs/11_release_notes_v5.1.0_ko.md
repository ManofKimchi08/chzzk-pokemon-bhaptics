# PokéChamps v5.1.0 릴리즈 노트 (Regulation M-C / Season M-6 규격)

> **배포 버전**: v5.1.0  
> **적용 규정**: 포켓몬 챔피언스 (PokéChamps) 2026 공식 「레귤레이션 M-C (시즌 M-6)」  
> **문서 번호**: docs/11_release_notes_v5.1.0_ko.md  

---

## 1. 개요 (Overview)

본 버전은 포켓몬스터 턴제 배틀 시스템을 최신 공식 규정인 **「레귤레이션 M-C」 (총 258마리 체제)** 로 전면 재정비하고, NDS 5세대 본가 사운드 감성의 **2계통 동적 오디오 엔진(Web Audio API 무지연 PCM 캐싱)** 을 완벽하게 이식·탑재한 메이저 업데이트입니다.

## 3. 실전 배틀 엔진 코어 (Battle Core Engine)

1. **배틀 모드**: 1v1 단판 승부 및 3v3 팀 엔트리 (선출 3마리 지정 및 교체 시스템)
2. **행동 우선순위 알고리즘**:
   - 1차: 기술 우선도 (Priority +3 속이다 > +1 기습 > 0 일반 기술)
   - 2차: 실질 스피드 (지닌도구 e.g. 구애스카프 1.5배, 랭크업, 상태이상 반영)
   - 3차: 동속 시 50:50 무작위 난수 롤
3. **PP 시스템 및 발버둥 (Struggle)**:
   - 각 기술 사용 시 잔여 PP 1 차감 (프레셔 특성 추가 차감)
   - 모든 기술의 PP가 0일 때 위력 50 노말 물리 기술인 '발버둥' 강제 발동 (반동 데미지: 최대 HP의 25%)
4. **메가진화 (Mega Evolution)**:
   - 46종 본가 메가진화 + 커스텀 메가진화 지원
   - 기술 선택과 동시에 메가진화 선언 가능 ➔ 턴 시작 즉시 타입/종족값/특성 인스턴스 갱신
5. **실전 지닌도구 28종 메커니즘**:
   - 생명의구슬, 구애머리띠, 구애안경, 구애스카프, 기합의띠, 먹다남은음식, 돌격조끼, 울퉁불퉁멧, 풍선, 탈출버튼, 레드카드
   - 18종 속성별 주얼 (normal_gem ~ fairy_gem): 1회 한정 1.3배 부스트 후 소모
6. **3중 방어적 기절(Faint) 가드**:
   - 데미지 계산 루프, 연출 타이머 대기, 턴 종료 처리 시 체력 0 포켓몬의 즉시 기절 처리 (0 HP 좀비 버그 원천 차단)

## 4. 2계통 동적 오디오 엔진 (Dual BGM & SFX Engine)

1. **5세대 본가 공식 테마 & 동적 500ms 크로스페이드**:
   - 통상 배틀: bgm_battle_trainer.mp3 (무한 루프)
   - 위기 배틀: bgm_battle_low_hp.mp3 (전투! 위기!)
   - 승리 팡파레: bgm_victory_trainer.mp3
   - 위기 판정 고증: aliveCount === 1 && (currentHP / maxHP <= 0.20) (생존 포켓몬 1마리 & 체력 20% 이하)
   - 체력 회복 시 즉시 통상곡 복귀 및 HUD 경보 사이렌(🚨) 연동
2. **레이턴시 0ms Web Audio API PCM 버퍼 캐싱**:
   - hit.wav, hit_strong.wav, faint.wav, flee.wav, PRSFX- Earthquake.wav, PRSFX- Psychic.wav, PRSFX- Muddy Water.wav를 메모리에 사전 디코딩하여 타격 즉시 발청
3. **독립 SFX 볼륨 & 음소거 (LocalStorage 영구 보존)**:
   - BGM과 분리된 전용 SFX 슬라이더 및 원클릭 음소거 기능
